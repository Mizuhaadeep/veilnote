不是编辑器。是文档。

用 Block 组织内容，而不是把所有东西塞进一个输入框。

01

图文、文件、定位混排

文本、图片、文件和地点按顺序流动；插入后自动生成新的空文本块并聚焦。

02

点击哪里，从哪里编辑

阅读模式记录点击字符的精确 offset，进入编辑时光标落在原位，列表不跳到底部。

03

单篇笔记独立上锁

每篇笔记独立密码。数据库只保存 SHA-256 哈希；锁定卡片隐藏标题、正文与时间。

04

纯本地存储

Room + DataStore；可选 SAF 公共目录，自动同步 `.veil` 文件。无账号、无网络权限。

05

玻璃与雾

低透明度玻璃卡、环境渐变、弹簧动效。全量/极简模式自由切换。

06

开源

Kotlin + Jetpack Compose 编写，采用 MIT License 开源。欢迎 Issue 与 PR。
